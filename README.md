# Speed Press

A Chrome extension that lets you temporarily speed up a Loom video by holding down the mouse button.

## Installation

1. Go to `chrome://extensions`
2. Enable **Developer mode** (toggle in the top right)
3. Click **Load unpacked**
4. Clone/Download the source code and select the folder where Speed Press is located
5. Visit a Loom video page, start playing a video, then **click-and-hold** to speed up

## Usage

- **Hold** the mouse button anywhere on the page while a video is playing → speed increases
- **Release** → speed returns to normal
- Click the extension icon to choose your press speed: **2x · 2.5x · 3x · 3.5x · 4x** (default: 3x)

> Long press only activates when the video is already playing — clicking while paused works normally.
